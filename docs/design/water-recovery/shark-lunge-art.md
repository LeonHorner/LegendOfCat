# Camera-facing shark artwork

OpenAI ImageGen generated the three jaw poses on 2026-11-13. The exact model ID
was unavailable. PhotoCraft 0.23.1 MCP resized and exported the transparent
atlas to `Assets/Game/Resources/WaterRecovery/shark-lunge-frames.png`.

The requested jump scare starts with a vertical strike below Mika, then the
shark rises toward the camera. The game centers the open mouth as it expands
into blackout. The artwork is original generated material under the repository
asset terms.

## Generation prompt

Transparent game sprite atlas, exactly three equally sized cells in a wide 3:1 single horizontal row. Each shows the SAME realistic painted great white shark seen head on, facing directly into the camera with symmetrical frontal foreshortening, from below slightly so the white underside and jaw are visible. Large head in center, small dark eyes set to sides, grey slate upper snout, cream underside, rear body and fins recede behind head. Stable facial proportions and identical centered position in each cell, generous transparent padding, fully separated. Left cell jaws shut. Middle cell jaws opening with small ivory teeth and dark mouth. Right cell mouth open very wide lunging toward camera, a large dark almost-black cavity framed by realistic teeth and gray snout. Each sprite includes head and a little receding body and fins. Subtle realistic hand-painted texture matching a naturalistic 2D river platformer. No text, no water, no background, no blood, no victim. True transparent alpha. Designed for a brief scary camera-facing bite animation.
