# Rejected Mika experiments

Archived on 2026-10-24 at the user's request. Everything here is outside Unity's
Assets tree, so it is neither imported nor compiled. Original relative paths
are retained below this directory, including Unity .meta files and GUIDs.
`manifest.json` records every original path and SHA-256; all moves/copies were
verified byte-for-byte. Eight files are snapshots of active code/metadata before
removing the legacy animation path; other entries were moved.

Archive files are marked `-text` in .gitattributes so checkout line-ending
conversion cannot invalidate the preservation hashes on Windows or Linux.

These files document the rejected cutout/IK and optical-flow experiments, not
production assets. Their five gait tests tested mechanical properties only.
Historical scripts retain their original paths and are not runnable tooling for
the current game. Restore only deliberately, following the recorded rejection
and review gate; do not copy them back into Assets as an automatic fix.

The accepted four-frame run source, original sprite assets and MikaOriginal
Resources prefab remain active. The live movement set and tests are maintained
separately. Earlier prompts, screenshots and recordings remain in the parent
authoring documentation. Historical source paths in ASSETS.md resolve through
this archive prefix. Original license/provenance records still apply unchanged.
