# Stomp encounter prototype

Issue #12. Open **Stomp lab (prototype)** from the main menu. This isolated runtime arena reuses CatController, CatMotion, CatInput and MikaOriginal; it does not alter the movement course, campaign, saves or character artwork.

## Provisional rules for user review

A stationary target previews a ground attack for 1.2 seconds (striped ground band), attacks for 0.35 seconds (solid band), then exposes its white head for 1.8 seconds. Labels and silhouettes distinguish the phases without depending on hue. The band's bounds exactly match the ground hazard. The target body remains dangerous from the side; descending feet must cross the head's top during recovery. A hit immediately closes the opening, removes one of three target health points and bounces Mika at 10 units/second. No stomp button is added.

Mika has three provisional health points. Damage gives 1.1 seconds of protection, separates Mika from the target and launches her clear. Ground attacks can be jumped over. Jump release does not cut the automatic bounce; ordinary jumps retain their existing release behavior. Swept body/feet checks cover crossings between physics samples. Presentation uses the same state that resolves each fixed-step collision; visual effects do not delay simulation.

Retry (R / controller Select) and full restart (Backspace / controller LB) reset the entire encounter through RunLifecycle.ResetTransientState, including health, attack phase, protection, impact, momentum and input buffers. Pause (P / controller RB) freezes physics and combat timers. Both win and loss retain Retry and Menu; no automatic retry cost is imposed. Menu is Esc / controller Start. Move/jump use the existing shared actions, including controller bindings. Touch UI is outside scope.

The component supports its default unit scale and translation. Rotation or scaled arena instances are not supported tuning contracts. There is no production boss identity, final difficulty or additional traversal ability.
