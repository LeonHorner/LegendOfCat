# Boss sprite generation

Built-in image_gen, transparent_background=true. Original generated PNGs retained unchanged. Runtime rendering applies an alpha cutoff to suppress translucent glow; metadata records opaque bounds.

## Forge
Use case: stylized-concept. Asset type: transparent game sprite sheet. Create a clean 2D side-view pixel-art animation sheet for ONE forge boss, a squat charcoal armored fire salamander with orange furnace belly, turquoise gem on forehead, chunky paws, expressive face. Cute yet formidable, consistent with a clean orange cat platformer sprite, bold dark outlines, flat 3-tone shading, no blur. Exactly 4 columns by 2 rows of equal cells on a 1536x1024 transparent canvas. Eight full-body poses of the SAME character facing LEFT, same size and baseline, with generous empty margins in EVERY cell. Row1: idle, breathing, windup cheeks puffed, fire attack mouth open. Row2: tired vulnerable turquoise gem glowing, hurt recoiling, crouch, defeated curled sleeping. No projectile outside body. No text, no labels, no scenery, no shadows outside silhouette, no border, no white background. Every pose wholly inside its cell.

Bold clean dark outline, crisp flat three-tone shading, match a polished orange cat platformer, no painterly texture, no blur. Row 2: breast gem exposed turquoise vulnerable; hurt recoil; wings folded guarding; defeated sleeping eyes closed. Strong readable wing motion, retain exact character proportions across eight poses. No environment, no floor, no external particles or shadows, no text, no labels, no checkerboard or white background. All eight complete silhouettes must stay entirely within their individual cells.
