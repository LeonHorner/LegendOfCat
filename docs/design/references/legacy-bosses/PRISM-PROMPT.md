Use case: stylized-concept. Create a NEW clean 2D side view pixel-art game boss animation sheet. Cute but imposing, polished bold dark contours and limited 3-tone pixel shading matching an orange cat platformer. Keep all silhouette connected; no detached crystals, no particles, no glows outside body, no ground shadow, no backdrop, no checkerboard, no text or labels. Actual transparent alpha.
