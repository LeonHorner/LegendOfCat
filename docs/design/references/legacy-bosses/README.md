Historical reference assets from the Java game, archived on 2026-10-23. These are inspiration and animation references, not the approved final Unity character designs. The new painted 2D direction remains authoritative.

Generation records: [initial sheets](PROMPTS.md), [forge/owl animation revision](PROMPTS-v2.md), [prism dragon](PRISM-PROMPT.md). The prism heading was translated to English; generation prompt content is preserved. PNG and JSON files were copied unchanged and verified against the local originals using SHA-256.

The generation records identify the built-in OpenAI image generation tool. Exact model identifiers, original generation dates and original input reference images are not available in this archive; do not invent them or claim complete provenance. Archive date is not generation date. Human direction retained a stomp boss and flying owl/dragon ideas, while permitting redesign. Artwork follows ASSET-LICENSE.md where rights exist; generated provenance does not establish copyright or exclusivity.

JSON files describe legacy extraction/bounds and are not Unity animation controllers. These files are documentation-only and are not imported into Assets or included in game builds. Review silhouette isolation, pivot consistency, margins and motion before any production reuse. No external Java folder is needed to view this archive.
